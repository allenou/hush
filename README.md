# Hush

Hush is a local-first Chrome extension for visually marking unwanted search results, advertising results, URLs, domains, and selected page elements.

Hush supports Google, Baidu, Bing, 360 Search, Sogou, Yahoo!, Yandex, and DuckDuckGo on their explicitly declared search domains. Rules, optional search history, statistics, preferences, and backups remain on the user's device.

## Development

```bash
npm test
npm run build
npm run zip
```
