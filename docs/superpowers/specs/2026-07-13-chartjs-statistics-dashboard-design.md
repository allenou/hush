# SearchKit Chart.js 统计仪表盘设计

## 目标

使用 Chart.js 增强选项页“概览”和扩展弹窗的统计能力，并将视觉系统调整为用户确认的淡紫灰、白色、海军蓝、青绿与黄绿色组合。统计增强必须复用现有存储数据，不引入数据迁移，也不改变现有业务流程。产品文案遵循“界面已经直接表达的内容不再重复说明”的原则。

## 范围

### 包含

- 选项页概览增加 7 天 / 30 天趋势切换。
- 概览展示当前区间总量、日均值和峰值。
- 使用 Chart.js 折线图展示拦截趋势。
- 使用 Chart.js 环形图展示广告、域名和其他拦截的累计分布。
- 使用 Chart.js 横向条形图展示 Top 10 高频被拦截域名。
- 弹窗将现有 CSS 柱状图替换为 Chart.js 7 日迷你折线图。
- 更新共享基础色系和导航视觉，使选项页各标签的颜色语言一致。
- 调整概览页和弹窗布局，使其符合已确认的趋势优先设计。
- 移除整个产品中重复标题、控件或数据含义的描述性文案。
- 重新设计概览页累计拦截卡片，并移除三张统计卡的彩色顶部边框。

### 不包含

- 不新增或迁移 `ExtensionStorage` 字段。
- 不改变规则、搜索历史和设置页的业务流程。
- 不在弹窗加入 7 天 / 30 天切换。
- 不增加服务端统计、同步或遥测。
- 不提交或推送 Git 变更。

## 视觉方向

视觉参考采用轻量医疗仪表盘风格，但内容和组件结构保持 SearchKit 自身语义：

- 页面背景：淡紫灰，用于形成柔和的画布层级。
- 导航与卡片：白色，配合轻边框和低强度阴影。
- 主要文字：深海军蓝，替代纯黑色作为主文字和大数字颜色。
- 品牌与趋势图：低饱和青绿。
- 关键指标和选中状态：黄绿色只用于控件状态、图表或局部强调，不使用彩色顶部边框区分统计卡。
- 图表辅助分类：柔和紫色；必要时使用珊瑚色作为补充，但不作为主警告色的替代。
- Header 使用白底，不使用黑色或整条深绿色背景。

选项页保留现有横向导航。概览采用“趋势优先”结构：顶部为页面标题与区间选择，其下由累计拦截卡片独占一行，三张区间指标卡排列在下一行；拦截趋势卡片再独占一行，类型分布和高频域名排列在其后的双列区域。

累计拦截采用白底“数据中枢”卡片：左侧以“累计拦截”和大号累计数字为主要信息，单位与数字同行；右侧以两个紧凑数据块展示今日拦截和规则数量。卡片使用淡青绿光晕与低对比盾牌水印建立品牌识别，不使用实色大面积背景、彩色边框或重复趋势信息。

三张区间统计卡统一使用普通边框和白色背景，不再通过黄绿、青绿、紫色顶部边框分类。区间总量与峰值将“次”作为数字单位展示；日均使用“次/日”；峰值日期作为必要上下文保留。范围切换器已经表达 7 天或 30 天，因此区间卡不再重复“每日拦截次数”等说明。

弹窗沿用相同视觉语言，保留累计、今日、站点状态和设置入口，只将 7 日趋势升级为紧凑折线图。

## 文案精简原则

删除界面本身已经直接表达的说明：

- 概览页副标题，以及趋势、构成、高频域名卡片的解释文字。
- 规则页“管理所有屏蔽规则”。
- 搜索记录页“所有搜索引擎的搜索历史，点击可重新搜索”。
- 设置页分组级的“控制规则匹配行为，按需开启或关闭”“记录搜索关键词和使用的搜索引擎”“切换扩展界面的显示语言”。
- 新增规则弹窗“输入域名或完整链接地址”，因为输入框占位符已经表达输入内容。

保留用户无法只凭标题或控件准确推断的信息：

- 设置项的具体匹配行为和关闭后的影响。
- 数据备份包含的数据范围、导入替换风险和操作反馈。
- 域名与完整链接的规则差异及输入错误信息。
- 空状态中的下一步操作建议。
- 教学模式、页面选取器和屏蔽操作的即时指引。
- 单位、日期、状态、无障碍名称与图表 Tooltip。

中英文语言包同步删除不再使用的文案键，避免保留失效翻译。

## 架构

### 统计派生模块

新增纯 TypeScript 统计模块，负责：

- 按本地日期生成连续的 7 天或 30 天序列。
- 将缺失日期补为 `0`。
- 从序列计算区间总量、日均值和峰值。
- 生成拦截类型分布，确保“其他”数量不会为负数。
- 为 Chart.js 组件提供稳定、可测试的数据结构。

该模块不直接读取 `chrome.storage`，不依赖 Svelte，也不创建 Chart.js 实例。

### Chart.js Canvas 组件

新增共享的 Canvas 生命周期组件，接收 Chart.js 配置并负责：

- 在 Svelte `onMount` 后创建图表。
- 输入数据、尺寸或语言标签变化时更新图表。
- 组件卸载时销毁 Chart.js 实例。
- 为 Canvas 设置可访问名称。

Chart.js 使用按需注册，范围只覆盖折线图、环形图、横向条形图、Tooltip、Legend 和必要比例尺，避免引入 `chart.js/auto` 的完整注册成本。

### 页面组件

概览组件负责区间选择状态、统计卡片和三类图表的组合。弹窗负责展示固定 7 日序列和迷你折线图。两处共用统计派生模块和 Canvas 生命周期组件，但分别维护适合自身尺寸的 Chart.js 配置。

## 数据流

```text
chrome.storage.local
        ↓
storage.get() / subscribe()
        ↓
统计派生模块
  ├─ 7/30 天连续序列
  ├─ 区间总量 / 日均 / 峰值
  ├─ 类型分布
  └─ Top 域名
        ↓
Dashboard / Popup
        ↓
Chart.js Canvas 组件
```

区间切换只改变前端派生状态，不写回存储。存储订阅触发时重新派生数据并更新现有图表实例。

## 数据定义

### 趋势

- 数据源：`ExtensionStorage.stats`。
- 可选范围：最近 7 天、最近 30 天。
- 默认范围：最近 7 天。
- 缺失日期：补零。
- 日期边界：使用本地日历日期，避免 UTC 转换导致本地日期偏移。

### 指标

- 区间总量：当前范围每日计数之和。
- 日均值：区间总量除以范围天数，显示一位小数。
- 峰值：范围内最大的日计数，并显示对应本地化日期；全零时峰值为 `0`。
- 统计数字的单位直接与数字组合，避免另起一行放置解释性文字。

### 类型分布

- 广告：`adBlockCount`。
- 域名：`domainBlockCount`。
- 其他：`max(0, blockCount - adBlockCount - domainBlockCount)`。
- 图表无总量时显示空数据状态，同时保留文本形式的零值。

### 高频域名

- 数据源：`blockedDomainStats`。
- 按现有存储顺序展示最多 10 项。
- 无数据时显示现有本地化空状态，不创建空条形图。

## 图表行为

### 选项页趋势图

- 类型：带轻透明填充的折线图。
- 主色：青绿。
- 数据点默认精简，仅在 Hover/Tooltip 时强调。
- 7/30 天切换使用分段控件。
- Y 轴从零开始；网格线使用浅灰紫。
- Chart.js 横坐标是日期标签的唯一展示来源，不在 Canvas 下方额外输出首尾日期 DOM，避免起点和终点重复。

### 类型分布图

- 类型：环形图。
- 颜色：青绿、黄绿、柔和紫。
- 中心或相邻文本展示主要分类和占比。
- 关闭 Chart.js 自带图例，避免与普通 DOM 图例重复。
- 普通 DOM 图例是唯一可见图例，同时展示分类名称、颜色标识与实际数量，以保留无障碍和非 Canvas 信息。

### 高频域名图

- 类型：横向条形图。
- 最多 10 项，长域名标签截断但 Tooltip 显示完整值。
- 条形使用主色与辅助色，数值同时以文本形式呈现。

### 弹窗趋势图

- 类型：无坐标轴标题的 7 日迷你折线图。
- 关闭图例，保留简洁 Tooltip。
- 固定高度，避免弹窗因数据变化跳动。

## 响应式与可访问性

- 宽屏下累计拦截和拦截趋势分别独占一行，三张区间指标卡保持三列，类型分布与高频域名组成双列。
- 中等宽度下图表重排为两列或单列。
- 小宽度下选项页内容单列；弹窗维持固定宽度。
- Canvas 必须提供本地化的 `aria-label`。
- 关键数字、分类数量和空状态必须存在于普通 DOM 文本中，不能只存在于 Canvas。
- 颜色不是唯一的信息区分方式；图例和文本标签必须保留。

## 错误与空状态

- Chart.js 创建失败时不影响统计卡片和文本数据展示。
- 输入数组为空或字段缺失时使用零值派生结果。
- 全零趋势仍显示稳定坐标范围，不制造虚假波动。
- Top 域名为空时复用 `noData` 文案。
- Dashboard、规则页和搜索记录页的缺省区域统一使用透明背景，不使用灰色或半透明填充。
- 完整缺省面板保留虚线边框、间距、图标和下一步指引；图表内部空状态遮罩保持透明，仅居中显示文案。
- 图表更新前检查 Canvas 与实例状态，卸载后不再更新。

## 国际化

- 日期、星期、图表 Tooltip、图例、指标标题和可访问名称通过现有本地化工具生成。
- 语言变化后重新生成 Chart.js 标签并更新实例。
- 新增中文和英文文案键，保持现有语言覆盖范围。

## 测试与验证

### 纯函数测试

- 生成完整 7 天序列并补零。
- 生成完整 30 天序列并补零。
- 使用本地日期处理跨月边界。
- 计算区间总量、日均值和峰值。
- 全零数据返回稳定指标。
- 类型分布的“其他”数量不为负数。

### Svelte 组件测试

- 概览默认显示 7 天状态。
- 点击后切换到 30 天状态并更新派生数据。
- 无域名数据时显示空状态。
- Canvas 存在本地化可访问名称。
- 语言变化后 Chart.js 横坐标日期和图表配置更新。
- 趋势卡不输出额外 `.chart-date-axis` 或 `.chart-date-label` DOM。
- 构成图关闭 Chart.js 图例且只保留一组 DOM 图例。
- 所有缺省状态相关样式不包含非透明背景声明。
- 累计拦截卡片包含累计、今日和规则三组必要数据，不包含重复趋势说明。
- 三张区间统计卡不再包含彩色顶部边框类或重复范围说明。
- 已确认删除的描述性本地化键不再被产品组件引用。

### 完整验证

- 运行新增测试并确认先失败后通过。
- 运行 `npm test`。
- 运行 `npm run build`。
- 在浏览器中检查选项页概览、7/30 天切换、响应式布局和弹窗尺寸。
- 检查控制台无 Chart.js 重复实例、Canvas 复用或卸载相关错误。
